Luma: Apple & Perceived Brightness

Apple uses luma (perceived brightness) to set text color based on background color. Apple divides the full luma range into equal halves, providing a simple and consistent decision boundary.

When Safari uses a webpage background-color to color browser UI, it also calculates the background-color luma to set browser UI text color:

luma ≤ 127.5Background is dark: Safari uses light text
luma > 127.5Background is light: Safari uses dark text

Try it in the Safari Color Tinting demo.

Luma

Rec. 709 (ITU Recommendation BT.709) is the international standard for HDTV. It defines how to calculate luma from the red, green and blue values of a color.

Luma is a weighted sum of gamma-encoded RGB values. In video, it represents the brightness of an image: its black-and-white part. Luma is not the same as relative luminance, which applies weights to linear RGB values, and it does not exactly represent the luminance of an image (Wikipedia: Luma). Of the three Rec. 709 weights, green is the largest and blue is the smallest.

Luma Formula

Y = ( 0.2126 × R ) + ( 0.7152 × G ) + ( 0.0722 × B )

Implementation Example

function selectThemeWithLuma(bgColor) {
  // remove leading #
  let hex = bgColor.replace(/^#/, '');

  // parse RGB components from hex
  const r = parseInt(hex.substring(0, 2), 16);
  const g = parseInt(hex.substring(2, 4), 16);
  const b = parseInt(hex.substring(4, 6), 16);

  // calculate Rec. 709 Luma using standard coefficients
  const Y = 0.2126 * r + 0.7152 * g + 0.0722 * b;

  // threshold at midpoint: 127.5
  // Y ≤ 127.5 = dark background, use light text
  // Y > 127.5 = light background, use dark text
  return Y <= 127.5;
}

Alternatives

WCAG Relative Luminance

W3C Web Content Accessibility Guidelines (WCAG) define relative luminance from 0 (black) to 1 (white), using the Rec. 709 weights on linearized sRGB values. At level AA, the contrast ratio between text and background must be at least 4.5:1, or 3:1 for large text (18 pt, or 14 pt bold). Above a relative luminance of about 0.179, black text has a higher ratio than white text (Lea Verou, an editor of W3C’s CSS Color specifications).

Oklab Lightness

Oklab, by Björn Ottosson, is designed to predict perceived lightness, chroma and hue. Its L is perceived lightness on a scale from 0 to 1, with 0.5 at the midpoint.
