Safari Color Tinting: Demo

Safari 15.0 or above required

Body Background

Fixed Position Background

Meta Theme Color

Safari tints its user interface to match the background color or a fixed element at the top or bottom edge. Learn more: github.com/andesco/safari-color-tinting

Users can enable or disable browser UI color tinting in Safari 26:

macOS: Safari › Settings › Tabs › Appearance: ✓ Show color in tab bar

iOS: Settings › Apps › Safari › Tabs: Allow Website Tinting ✓

Fixed Element Without Tinting

A neutral backdrop-filter stops Safari from sampling the background color.

Tinting with a Minimal Fixed Element

#top-bar { position: fixed; top: -7px; left: 0; width: 100%; height: 12px; }
#bottom-bar { position: fixed; bottom: -8px; left: 0; width: 100%; height: 12px; }

Hidden Fixed Elements

Safari ignores a fixed element that is hidden:

#top-bar { position: fixed; top: -12px; left: 0; width: 100%; height: 12px; }
#bottom-bar { position: fixed; bottom: -12px; left: 0; width: 100%; height: 12px; }
